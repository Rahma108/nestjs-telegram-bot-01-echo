# 🤖 NestJS Telegram Todo Bot

A Telegram Todo Bot built with **NestJS**, **Telegraf**, **MongoDB**, and **Mongoose**.

## ✨ Features

### 👋 Echo Bot

* Reply to user messages.

### 👤 Registration Flow

* `/start`
* `/register`
* Collect user name
* Collect user age
* `/cancel`

### 📝 Todo Management

* Add Task
* View Tasks
* Edit Task
* Delete Task (Soft Delete)
* Restore Task
* Complete Task
* Toggle Task Status
* Search Tasks
* Task Statistics
* Pagination

### 🆕 New Features

* Due Date Support
* Priority (Low / Medium / High)
* Multi-step task creation workflow

## 🛠 Tech Stack

* NestJS
* TypeScript
* Telegraf
* MongoDB
* Mongoose
* Repository Pattern

## 📌 Commands

* `/start`
* `/register`
* `/cancel`
* `/add`
* `/tasks`
